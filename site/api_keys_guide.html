API Keys & Authentication Guide

Learn how to obtain free API credentials for Pexels, Pixabay, and Unsplash, and configure them permanently for the stock-fetcher CLI.

Provider Authentication Matrix

Provider Environment Variable Key Required? Free Tier Quota Portal Link
Pexels PEXELS_API_KEY Yes 200 req/hr (20,000/mo) pexels.com/api
Pixabay PIXABAY_API_KEY Yes 100 req/minute pixabay.com/api/docs
Unsplash UNSPLASH_API_KEY Yes 50 req/hr (Demo tier) unsplash.com/developers
Flickr None No Uncapped Public Scraping Zero-Configuration

How to Obtain API Keys

1. Pexels

Pexels provides immediate API access upon creating a developer application. Approval is automated and instantaneous without credit card requirements.

  1. Create an Account: Visit pexels.com and sign up or log in.
  2. Access Developer Portal: Open pexels.com/api/new/.
  3. Describe Your App: Fill in a title (e.g. CLI Stock Fetcher) and select personal scripting usage.
  4. Copy the Key: Your 56-character API token is generated immediately.
Quota & Limits

The free tier provides 200 requests per hour and 20,000 requests per month. Exceeding this returns HTTP 429.

2. Pixabay

Pixabay links your API key directly to your user account without requiring an application approval workflow.

  1. Create an Account: Register at pixabay.com.
  2. Open Documentation: Visit pixabay.com/api/docs/ while logged in.
  3. Locate Your Personal Key: Look under the "Search Images" or "Parameters" section for the green highlighted box: 
    key: 12345678-abcdef0123456789abcdef012
  4. Copy the Complete Key: Copy the full string including the hyphen.
Quota & Limits

Pixabay allows 100 requests per 60-second window across all endpoints on the free plan.

3. Unsplash

Unsplash requires creating a developer application within their official API portal.

  1. Register as Developer: Go to unsplash.com/developers.
  2. Create Application: Go to Your apps → New Application and accept terms.
  3. Retrieve Access Key: In your application details, locate the Keys section and copy the Access Key.
Security Note

Always use the Access Key, never the Secret Key. stock-fetcher uses standard client authentication headers (Authorization: Client-ID <ACCESS_KEY>).

4. Flickr (Zero Configuration)

Flickr integration uses an integrated HTML parser targeting Creative Commons media.

  • No API key required.
  • No registration or credential approval required.
  • Works immediately out of the box in the CLI and Python SDK.

Configuring Keys for the CLI

Method 1: Persistent Shell Profile (Recommended)

Add environment variables to your shell startup file so they are always available in your terminal:

macOS / Zsh (Default on macOS)

# Add to ~/.zshrc
export PEXELS_API_KEY="your_pexels_key_here"
export PIXABAY_API_KEY="your_pixabay_key_here"
export UNSPLASH_API_KEY="your_unsplash_key_here"

# Apply changes immediately
source ~/.zshrc

Linux / Bash

# Add to ~/.bashrc
export PEXELS_API_KEY="your_pexels_key_here"
export PIXABAY_API_KEY="your_pixabay_key_here"
export UNSPLASH_API_KEY="your_unsplash_key_here"

# Apply changes immediately
source ~/.bashrc

Method 2: Project-Level .env File

Create a .env file in your workspace directory:

PEXELS_API_KEY=your_pexels_key_here
PIXABAY_API_KEY=your_pixabay_key_here
UNSPLASH_API_KEY=your_unsplash_key_here

Load into your environment prior to executing commands:

export $(grep -v '^#' .env | xargs)
stock-fetcher search pexels "architecture"

Method 3: Direct Command Flag (--api-key)

Pass an explicit token using --api-key (or -k):

stock-fetcher search pexels "alpine lake" --api-key "your_pexels_key_here"

Method 4: Global Fallback Variable

If you prefer a single unified environment variable, configure STOCK_FETCHER_API_KEY:

export STOCK_FETCHER_API_KEY="your_universal_key"

Verifying Your Configuration

Use the built-in diagnostic commands to verify that your keys are detected properly without consuming quota: 

# Inspect masked environment variables
stock-fetcher keys

# Inspect provider readiness table
stock-fetcher providers

Security Best Practices

  • Never commit credentials: Always ensure .env is included in your .gitignore.
  • Restrict file permissions: Protect your shell startup files: chmod 600 ~/.zshrc.
  • Rotate leaked keys: If an API token is accidentally pushed to a repository, revoke and regenerate it immediately in the provider dashboard.
