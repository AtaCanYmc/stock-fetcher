Terminal Reference

CLI Command Line Reference

Explore commands, flags, output formats, batch download arguments, and Unix pipeline recipes for the stock-fetcher executable.

Installation

Method 1: Homebrew (macOS & Linux)

brew tap AtaCanYmc/tap
brew install stock-fetcher

Method 2: Pip

pip install "stock-fetcher[cli]"

Command Overview

Command Description
stock-fetcher search PROVIDER TERM Query a specific provider or all providers.
stock-fetcher find TERM Shortcut to query all configured providers concurrently.
stock-fetcher download URL Download a single image file from a direct URL to disk.
stock-fetcher providers Display supported providers, modes, and readiness status.
stock-fetcher keys Audit environment API key credentials with safe masking.
stock-fetcher version Print version string, runtime information, and platform details.

search Command

stock-fetcher search [OPTIONS] PROVIDER TERM

Arguments

Argument Allowed Choices Description
PROVIDER pixabay, pexels, unsplash, flickr, wikimedia, openverse, all Target image provider or all.
TERM String Search query (e.g. "minimalist architecture").

Flags & Options

Option Short Default Description
--limit -l 5 Maximum images to fetch per provider (clamped 1–100).
--page -p 1 1-indexed page number for deterministic pagination.
--cursor None None Opaque deterministic pagination cursor token.
--api-key -k None Explicit provider token (overrides environment variables).
--format -f table Output format: table, json, csv, or urls.
--download -d false Automatically download all retrieved images to disk.
--output-dir -o ./downloads Destination directory when downloading images.

find Command

A fast convenience shortcut equivalent to running stock-fetcher search all TERM concurrently across all providers: 

stock-fetcher find "cyberpunk neon city" --limit 3 -f table

download Command

Downloads a single image from any valid HTTP/HTTPS URL with real-time transfer progress, size validation, and path traversal defense: 

stock-fetcher download "https://images.pexels.com/photos/123/original.jpg" -o ./wallpapers -n custom.jpg

providers & keys Diagnostics

Audit provider configuration and verify which credentials are recognized:

# Check provider readiness
stock-fetcher providers

# Audit environment credentials
stock-fetcher keys
API Keys Setup

To obtain free API keys for Pexels, Pixabay, and Unsplash and add them to your ~/.zshrc, see our dedicated API Keys Guide.

Environment Configuration

Provider Environment Variable Requirement
Pexels PEXELS_API_KEY Required for Pexels searches
Pixabay PIXABAY_API_KEY Required for Pixabay searches
Unsplash UNSPLASH_ACCESS_KEY Required for Unsplash searches
Flickr None Ready out-of-the-box (public feeds)
Wikimedia Commons None Ready out-of-the-box (MediaWiki search API)
Openverse OPENVERSE_API_KEY Optional (public tier works without key; OAuth token increases rate limits)

Unix Shell Pipeline Recipes

1. Pipe Original URLs to curl

Extract only direct image URLs and pipe into xargs for parallel downloading:

stock-fetcher search flickr "vintage aircraft" -l 3 -f urls | xargs -n 1 curl -O

2. Parse JSON Results with jq

Filter JSON output and extract specific metadata fields:

stock-fetcher search pixabay "aurora borealis" -f json | jq '.[].url_original'

3. Batch Download Directly

Download directly to disk with sanitized filenames in a single command:

stock-fetcher search flickr "alpine lake" -l 5 -d -o ./gallery
